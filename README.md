# pairwise-hit-reaction-direction

角色被侧面来的攻击打中却向后倒，受击方向取的是攻击者的朝向，而不是攻击者到角色的连线；方向算完直接塞进角色本地空间，角色转身后倒的方向跟着转；八方向阈值把斜后方攻击归到了正后方，动画看起来完全错；同一帧被三个人命中，最后一次命中覆盖了前两次，最重的伤害反而没表现；硬直时长固定 0.3 秒，轻击和重击看起来一样；击退初速与角色质量无关，重甲角色被小怪推着走；斜坡上击退向量没有投影到地面，角色被推进地里；网络同步只发受击动画名，客户端按自己的朝向播放，两边倒的方向不同；霸体状态下仍然播放受击位移，技能被硬生生打断；受击方向按相机朝向算，玩家转视角时同一次攻击表现不同。gameplay/hit_reaction_direction.py 是核心，tests/test_hit_reaction_direction.py 15个红。要修的是：用相对位置；世界空间；连续角度；取最强命中；按伤害定时长；按质量算击退；投影到地面；同步方向；霸体屏蔽位移；固定世界参考。

## 运行

```bash
python -m pytest tests -q
```
